Privacy Policy

Last updated: 18 November 2026

Mangole Clips Studio ("the tool") is a private application operated by Bee & I Productions e.U. (owner Laurenz Stolitzka), Graf-Starhemberg-Gasse 2B/4, 1040 Wien, Austria. It is used only by its operator for the operator's own social media accounts.

What the tool accesses on TikTok

When the operator connects a TikTok account, the tool receives an access token for that account. It uses the token only to (a) read the account's display name and (b) upload video files created by the operator to the drafts inbox of that same account.

What is stored

  • The access token and the display name are stored only locally on the operator's computer.
  • The videos are created by the operator and stored on the operator's computer.
  • No data of other TikTok users is read, collected, stored or shared.
  • The tool has no other users and uses no analytics or advertising trackers.

Sharing

No data is sold or shared with third parties.

Revoking access and deletion

Access can be revoked at any time in the TikTok app under Settings and privacy, Security and permissions, Apps and services. On request, or when access is revoked, the locally stored token and display name are deleted. Contact: the operator at the address in the legal notice above.
